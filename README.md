# ClassCatch

Mobile-first PWA for school/college students who miss classes. Features teacher-approved summaries, shared notes, homework tracking, quick quizzes, and role-based dashboards for Students, Teachers, and Class Representatives.

## Live Demo

Deployed via GitHub Pages at: http://127.0.0.1:5500/index.html

## Tech Stack

- **Frontend:** Vanilla HTML/CSS/JS (zero dependencies)
- **Backend:** Client-side relational database engine using localStorage
- **Architecture:** RBAC, PWA-ready, dark mode, responsive mobile-first

## Local Development

No build step required. Open `index.html` in any browser.
